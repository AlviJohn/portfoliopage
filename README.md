# Alvi Skariah John — Portfolio

A static, single-page portfolio built with React + Vite. AI-themed: an interactive
"embedding space" hero, token-streamed headline, dark/light themes.

## Edit content

All text lives in [`src/data.js`](src/data.js) — profile, impact stats, selected work,
experience, skills, education. Change it there; no component edits needed.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Import this repo at <https://vercel.com/new>.
2. Vercel auto-detects Vite — build command `npm run build`, output directory `dist`.
3. Deploy. Every push to `main` redeploys.
